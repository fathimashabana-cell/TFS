# Kozhi Koo Counter 🐓🔊 (കോഴി കൂവി കൗണ്ടർ) 🎯

> **The World's Most Scientifically Unnecessary Rooster Crow & Bass Frequency Analyzer**

### Team Members

### Project Description
A delightfully useless web application that listens to rooster crows (*kozhi koo*), counts them, and scientifically evaluates their decibel intensity, low-frequency 808 sub-bass rumble, and vocal characteristics to classify them into hilarious comedic archetypes with authentic village predictions.

### The Problem (that doesn't exist)
For thousands of years, roosters across Kerala and the world have been crowing at ungodly hours (4:00 AM) with zero quality control, zero decibel accountability, and zero frequency regulation. Village grandfathers wake up grumpy without knowing if the crow was an authentic *Nadan* acoustic signal or an existential plea from a broiler chicken facing the butcher's knife.

### The Solution (that nobody asked for)
We built an over-engineered, real-time Web Audio analyzer and counter that:
1. Detects live rooster crows using microphone threshold listening and FFT spectrum analysis.
2. Measures exact **Decibels (dB)** and **Bass Rumble Percentage** (20Hz - 280Hz chest vibration).
3. Classifies each crow into hilarious archetypes (e.g., *The 4:00 AM Existential Crisis Koo*, *The Subwoofer 808 Desi Machan*, *The Chilly Chicken Survival Panic*, *The Broken Bajaj Auto Carburetor*).
4. Generates absurd egg production forecasts, tracks village noise violation milestones, and issues an official printable **Panchayath Poultry Inspector Certificate**!

## Technical Details

### Technologies/Components Used
For Software:
- **Languages**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Audio Processing**: Web Audio API (`AudioContext`, `AnalyserNode`, FFT frequency analysis, BiquadFilter formants)
- **Visuals & UI**: HTML5 Canvas (Real-time frequency visualizer & interactive falling feather physics), Lucide Icons, Google Fonts (`Fredoka`, `Chewy`, `Plus Jakarta Sans`)
- **Storage**: Browser `localStorage` for persistent session tallies and high-score statistics

## Features

- **🌾 Natural Village Farm Aesthetic**: Rustic timber boards, terracotta clay accents, warm yolk yellow, and responsive mobile-friendly layouts.
- **🐓 Interactive Rooster Mascot ("Kozhi Chettan")**: Animated SVG rooster that reacts to loud sounds, opens beak wide when crowing, vibrates on heavy bass, and roasts you when poked.
- **🔊 5 Built-in Procedural Crow Synthesizers**: No live rooster nearby? Play authentic simulated crows (*Nadan Alarm*, *808 Sub-Bass*, *Chilly Panic*, *Auto Carburetor*, *Opera Diva*) generated purely in-browser using Web Audio oscillators and filters.
- **🎙️ Live Mic Listening & Auto-Detect**: Real-time microphone listener with sensitivity threshold and silence debouncing.
- **📁 Audio File Drag & Drop**: Drop any `.mp3` or `.wav` recording to analyze rooster crows from around the globe.
- **📜 Official Certified Koo Inspector Certificate**: Generate and print a stamped certificate of rooster competence.

## Implementation

### Installation
No complex dependencies or build steps required. Simply clone the repository:
```bash
git clone https://github.com/fathimashabana-cell/TFS.git
cd TFS
```

### Run
Open `index.html` in any modern web browser:
- **Option 1**: Double-click `index.html`
- **Option 2**: Run with a local static server:
```bash
# Using Python
python -m http.server 8000

# Or using Node
npx serve .
```
Then visit `http://localhost:8000`.
